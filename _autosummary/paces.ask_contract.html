paces.ask_contract#

The ask contract as types: the proposal a machine writes and the answers a human returns.

paces.ask produces and reads these two JSON documents (docs/alignment/07 §7.4), and every other UI (the real frontend, a CLI prompt, an agent) speaks the same two. They are declared here as pydantic models, so the shape is written once, load_answers validates against it, and the JSON Schema a TypeScript side needs comes from contract_schemas() and not from a second hand-written copy.

Field names are camelCase on the wire, as the page reads them. Times are decimal strings, as everywhere on paces’ wire.

>>> sorted(contract_schemas())
['answers', 'proposal']

What the page exports (paces.ask.load_answers() reads it).

corrections is a paces.corrections log, each entry validated by paces.corrections.normalize_corrections(). boundaries holds the cuts tapped when the proposal had none to correct, from 0 to the media’s end, as time strings or seconds.
